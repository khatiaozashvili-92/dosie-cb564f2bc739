# აჯიბადემის დოსიე

Acıbadem Maslak · 13–16 ოქტომბერი 2026 — სამედიცინო საბუთების დოსიე ერთ გვერდზე,
ტელეფონზე მორგებული.

**⚠️ ეს რეპოზიტორია შეიცავს პერსონალურ სამედიცინო და საიდენტიფიკაციო მონაცემებს**
(პაციენტის ნომერი, პასპორტის ნომერი, დიაგნოზები, ბარათის ქვითრები).
ბმული ნუ გაუზიარებ იმას, ვისაც ამ საბუთების ნახვა არ უნდა შეეძლოს.

სულ 81 საბუთი. ყველა იხსნება აპლიკაციიდანვე — PDF იხატება გვერდზე (pdf.js),
ფოტო ჩნდება იქვე, და ყოველთვის არის ღილაკი „ცალკე გვერდზე ↗“, რომ ტელეფონის
საკუთარი გამხსნელით ნახო და გაადიდო.

## ნავიგაცია

ექვსი ფოლდერი — ხუთი მიმართულება (რევმატოლოგია, გინეკოლოგია, ყელ-ყურ-ცხვირი,
მამოლოგია, ენდოკრინოლოგია) და „შეჯამება და ანალიზი“.
თითო მიმართულებაში სამი ქვეფოლდერია:

- **ჩეკი და ინვოისი** — ტერმინალის ჩეკი · ლირის ფატურა · დოლარის ინვოისი · ბანკის ქვითარი
- **დანიშნულება** — დაზღვევის ფორმა · ექიმის წერილი · რეცეპტი
- **კვლევების ჩამონათვალი და პასუხები** — რა დანიშნა ექიმმა და რა პასუხი მოვიდა

„შეჯამებაში“ ნაჩვენებია რა არის, რას აკლია ხარვეზი და რა უნდა მოითხოვო.
მონიშნული პუნქტები ინახება შენს ბრაუზერში (localStorage) — სხვა ტელეფონზე არ გადადის.

## ტელეფონზე მთავარ ეკრანზე დამატება

- **iPhone (Safari):** გახსენი ბმული → გაზიარების ღილაკი → „Add to Home Screen“
- **Android (Chrome):** გახსენი ბმული → ⋮ → „Add to Home screen“

ამის შემდეგ ჩვეულებრივი აპივით გაიხსნება, მისამართის ველის გარეშე.

## კოდი

გვერდი კოდით იხსნება. ერთხელ შეიყვან და ბრაუზერი დაიმახსოვრებს.
კოდის შესაცვლელად `index.html`-ში იპოვე `const PIN_HASH=` და ჩასვი ახალი რიცხვი —
როგორ გამოითვლება, იქვე კომენტარშია აღწერილი.

ეს მხოლოდ შემთხვევითი თვალისგან იცავს: `doc/`, `img/` და `full/` ფაილები
პირდაპირი ბმულითაც იხსნება. ნამდვილი დაცვისთვის საჭიროა პირადი რეპოზიტორია
(GitHub Pro).

## განახლება

ახალი საბუთი რომ დაამატო:

1. ჩააგდე ფაილი `doc/`-ში (PDF) ან `img/`-ში (ფოტო)
2. `index.html`-ში, `FILES` ობიექტში, შესაბამის ქვეფოლდერს დაამატე სტრიქონი:
   `{n:'სახელი', s:'აღწერა', h:'doc/ფაილი.pdf'}`
   (ფოტოსთვის დაამატე `t:'image/jpeg'`)
3. commit და push — GitHub Pages თვითონ განაახლებს 1–2 წუთში

## ტექნიკური

სტატიკური გვერდი, build-ის გარეშე. გარედან იტვირთება მხოლოდ Noto Georgian
(Google Fonts) და pdf.js (cdnjs). `robots.txt` და `noindex` საძიებო სისტემებს
კრძალავს.
